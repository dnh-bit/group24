## ۳) لیست تغییرات (برای گیت‌هاب / متنی)

### ✨ نسخهٔ 0.1.6 — آپدیت بزرگ از 0.1.2

**⏰ آلارم واقعی**
- اعلان تمام‌صفحه با `fullScreenIntent` روی صفحهٔ قفل
- زنگ اختصاصی ۸ ثانیه‌ای درون برنامه (۱۷KB، بدون فایل بیرونی)
- دکمه‌های «۵ دقیقهٔ دیگر» و «خاموش» روی اعلان
- زمان دلخواه ۰ تا ۱۲۰ دقیقه + گزینه‌های آماده
- انتخاب صدا: زنگ برنامه / زنگ گوشی / فقط لرزش / بی‌صدا
- کانال اندروید جدا برای هر ترکیب صدا/لرزش

**🎛 اعلان هر درس**
- سه حالت: آلارم / فقط اعلان / خاموش
- کشویی فهرست درس‌ها با خلاصهٔ شمارش
- روشن/خاموش کردن تک‌تک جلسه‌ها + «همه روشن / همه خاموش»
- دقیقهٔ آلارم اختصاصی برای هر درس
- پیش‌فرض کلی برای درس‌های تنظیم‌نشده

**🎓 امتحان**
- آلارم واقعی قبل از شروع (قابل تنظیم)
- یادآوری شب قبل، ساعت ۲۰:۰۰

**🔋 باتری و پس‌زمینه**
- پل نیتیو Kotlin برای باز کردن صفحهٔ درست هر برند
- شیائومی/ردمی/پوکو، هواوی/آنر، سامسونگ، اوپو/ریلمی/وان‌پلاس، ویوو/آیکو، ایسوس، نوکیا
- راهنمای گام‌به‌گام فارسی وقتی صفحهٔ اختصاصی نباشد
- اجازهٔ `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`

**🎬 اسلاید خوش‌آمد**
- فقط برای نصب تازه (کاربران فعلی نمی‌بینند)
- انتخاب پیش‌فرض آلارم/اعلان همان اول
- گرفتن هر دو اجازهٔ اعلان با یک لمس
- تشخیص برند و آزاد کردن باتری

**🧹 تنظیمات**
- شش بخش با ترتیب منطقی و آیکون
- یادآوری کلاس و امتحان در یک کارت
- درخواست اجازه فقط وقتی کم باشد

**🔕 کلاس‌های تک‌ساعته**
- پیش‌فرض بی‌اعلان (قابل روشن کردن)
- تفکیک «برگزار نشود» از «اعلان نگیرد»

**🎓 تغییر برنامه**
- گروه ۲۴: «مدیریت امور فرهنگی و تربیتی» (استاد سلطانی‌نژاد) از یکشنبه ۱۵:۳۰ به **سه‌شنبه ۱۴:۰۰–۱۵:۳۰**
- این تغییر روی نصب‌های موجود هم اعمال می‌شود

**🐞 رفع باگ‌ها**
- «Cannot add to an unmodifiable list» در نسخهٔ خالی
- ایمپورت: آرایهٔ بدون پوشش، ارقام فارسی، رنگ پالتی، `plan.name`، امتحان `year/month/day`
- شناسهٔ اعلان‌ها بر اساس جایگاه درس (بدون برخورد)
- تغییر اعلان روی گروه اشتباه وقتی دو گروه id یکسان داشتند
- دکمهٔ Autostart که به صفحهٔ بی‌ربط می‌رفت
